# Parties, Party Collections and Agents

> OpenREL user guidance | Aligned with OpenREL Specification V0.5.2 | CC BY 4.0

> This is implementation guidance. The specification and published RDF/SHACL definitions take precedence if any discrepancy is found.

ODRL Parties identify the assigner, assignee and other actors associated with rules and policies. A Party Collection can describe a group or role without naming a single individual.

OpenREL uses controlled vocabularies to express agent and role types relevant to research infrastructures. Distinguish the **identity** of an agent from the **role** the agent has in a specific request.

Assertions about affiliation, credentials, researcher status or organisational characteristics should be represented as contextual claims with appropriate validation, not inferred merely from an agent-type label.

See [Contextual Assertions](16_ContextualAssertions.md) and the agent-related schemes in specification A.5.6.

# Left Operands

> OpenREL user guidance | Aligned with OpenREL Specification V0.5.2 | CC BY 4.0

> This is implementation guidance. The specification and published RDF/SHACL definitions take precedence if any discrepancy is found.

ODRL Left Operands identify the quantity or characteristic against which a constraint is evaluated. OpenREL extends the available Left Operand registry for research data, access control and operational contexts.

A Left Operand is not the value supplied at runtime. It identifies what is being tested. Its operator and right operand establish the comparison; where a value is dynamic, the OpenREL parameter model may be used.

The specification's **A.6 Left Operands** section is authoritative for the OpenREL registry and external vocabulary adoption. Avoid treating an externally mapped concept as interchangeable without checking its semantics and intended evaluation context.

See [Parameters and Right Operands](10_RightOperands.md).
